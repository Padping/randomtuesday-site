How we work

Three commitments that shape every decision we make.

Never overwhelm

A tool that shows you everything shows you nothing. We design for the smallest useful screen: what matters now, with the rest one tap away.

Private by default

We collect as little as we can get away with. Where a product can work entirely on your device, it does — and we say so plainly rather than burying it in a policy.

Built to last

Small, focused releases that we can support for years. We would rather ship one thing that still works in 2030 than five that don't survive an OS update.
